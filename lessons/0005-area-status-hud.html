2. 两个节点组成一个屏幕提示

World (Node2D) ← world.gd ├── Player (CharacterBody2D) ├── Wall (StaticBody2D) ├── Trigger (Area2D) │ └── CollisionShape2D └── HUD (CanvasLayer) ← 新增：独立画布层 └── StatusLabel (Label) ← 新增：显示文字

图中省略 Player、Wall 的子节点；保留它们。HUD 是屏幕信息界面的常用名称。

CanvasLayer 给子节点提供独立画布。默认 layer = 1，绘制在默认世界画布之上；默认不跟随世界视口变换，适合屏幕提示。这个 Layer 是绘制顺序，不是第三课的碰撞 Layer。参见 官方 CanvasLayer 说明。

Label 继承 Control，负责显示普通文本。修改其 text 属性就能更新文字。参见 官方 Label.text 说明。

3. 在 World 中添加界面节点

以下使用本机 4.7.2 的英文控件名，中文用于对照。先停止游戏：按 F8（Stop，停止），Mac 功能键被占用时按 Fn+F8。确认顶部场景标签仍是 world，再点击顶部中央 2D。

3.1 创建 HUD

  1. 在左上 Scene → World 单击根节点，再点击 Scene 面板左上角的 ＋（Add Node，添加节点）。
  2. 在创建节点窗口的 Search（搜索） 框输入 CanvasLayer，选中同名类型，点击 Create（创建）。
  3. 在 Scene 中右键新节点，选择 Rename（重命名），输入 HUD，按 Enter。确认 HUD 与 Player 同级。
  4. 保持 HUD 默认属性：CanvasLayer 的 Layer（层） 为 1。本课无需修改它，也不需要进入碰撞设置。

3.2 创建 StatusLabel 并填入初始文字

  1. 在 Scene → World → HUD 选中 HUD，点击同一 ＋ 按钮，搜索 Label，选中 Label，点击 Create。
  2. 右键新 Label → Rename，输入 StatusLabel，按 Enter。确认它缩进在 HUD 下。
  3. 保持选中 StatusLabel，看右侧 Inspector（检查器）。顶部对象名应为 StatusLabel。清空 Filter Properties（筛选属性），在上方 Label 类属性区域找到 Text（文本） 多行输入框，填入 区域外。点击输入框外，使编辑生效。
  4. 位置、尺寸、字体先保留默认值。默认位置在画布左上角，Label 会为短文本提供最小尺寸。本课不需要创建 Label Settings 资源。
  5. 通过 Scene（场景）→ Save Scene（保存场景） 保存 world.tscn。macOS 的 Scene 菜单在屏幕顶部系统菜单栏，也可在场景工作区按 ⌘S。

找不到 Text？完整路径是 world 场景 → Scene → World → HUD → StatusLabel → Inspector → Label → Text。不要选 HUD，也不要双击脚本后在脚本资源的检查器里找。若 Label 属性区域折叠，先展开它。

立即运行一次：保持 world 场景，按 F6（Run Current Scene，运行当前场景），必要时 Fn+F6。左上角应显示“区域外”。这时进入区域，颜色仍变化，文字暂时不变化。看到文字后按 F8 停止，再继续。

4. 用已有信号更新文字

4.1 取得 Label 引用

在左下 FileSystem → res:// → world.gd 双击脚本。在已有 @onready 声明之后、func _ready() 之前，顶格添加：

@onready var status_label: Label = $HUD/StatusLabel

路径从挂脚本的 World 开始：先找直接子节点 HUD，再找它的 StatusLabel。$StatusLabel 会在 World 下直接寻找，层级不对。名称区分大小写。

4.2 每个回调只增加一行

  1. 在 _on_trigger_body_entered 的 if body == player: 内，紧接颜色赋值添加 status_label.text = "区域内"。缩进两个 Tab。
  2. 在 _on_trigger_body_exited 的同一条件内，紧接恢复颜色添加 status_label.text = "区域外"。缩进两个 Tab。
  3. 已有信号连接各保留一次。无需再去 Signals（信号） 面板连接，也无需改 Player 的 _physics_process()。

本课出生点在区域外，所以场景里保存的“区域外”是正确初始值。进入后，text 保留新值，直到离开时被改回；与第四课的颜色属性相同。若以后改成出生在区域内，需要重新审视初始化，当前先保留出生点。

动手后展开：完整 world.gd 核对版 
extends Node2D

@onready var player: CharacterBody2D = $Player
@onready var trigger: Area2D = $Trigger
@onready var original_modulate: Color = player.modulate
@onready var status_label: Label = $HUD/StatusLabel

func _ready() -> void:
	trigger.body_entered.connect(_on_trigger_body_entered)
	trigger.body_exited.connect(_on_trigger_body_exited)

func _on_trigger_body_entered(body: Node2D) -> void:
	if body == player:
		print("角色进入触发区域")
		player.modulate = Color(1.0, 0.45, 0.45, 1.0)
		status_label.text = "区域内"

func _on_trigger_body_exited(body: Node2D) -> void:
	if body == player:
		player.modulate = original_modulate
		status_label.text = "区域外"
		print("角色离开触发区域")

5. 验收一次完整往返

  1. 在 Script 代码区按 ⌘S 保存 world.gd，确认没有红色语法错误。点击顶部 world 标签，再按 F6。单独运行 player 场景不会出现 HUD。
  2. 点击游戏画面获取键盘焦点。出生时：图标原色，左上角显示“区域外”。
  3. 短按 W 接近上方 Trigger，每次约 0.1 秒。变色后松开按键：文字应变为“区域内”。停留两秒，文字、颜色都保持，进入日志不连续增加。
  4. 按 S 回到出生点附近，直到碰撞形状完全离开：颜色恢复，文字变为“区域外”。再进入一次，两项应再次同步变化。
  5. 文字应一直在屏幕左上角，不随 Player 移动。按 D 撞墙，应仍停住；保持 D 短按 W，应仍沿墙向上移动。松开后停止。
  6. 按 F8 停止。编辑器底部 Output（输出） 可核对“进入 → 离开 → 进入”日志。点击底部 Debugger（调试器）→ Errors（错误），检查本次运行没有新增错误。
验收链

原色／区域外 → 变色／区域内 → 停留保持 → 原色／区域外 → 再次进入同步变化。文字位置固定，墙仍阻挡，调试器无新增错误。

6. 按现象定位问题

找不到 HUD/StatusLabel，或给空对象设置 text

停止游戏，打开 world.tscn，在 Scene 展开 World 和 HUD，按第 2 节核对层级与大小写。确认脚本挂在 World、场景已保存，且运行的是 World。

颜色会变，文字一直是区域外

检测已经工作。检查修改的是 world.gd，进入回调内有 text 赋值，且脚本已保存。不要新增重复连接来解决这个问题。

文字没有出现

先停止运行，在 Scene 选中 World → HUD → StatusLabel，到 Inspector → Label → Text 确认初始值“区域外”。确认 Label 放在 HUD 下，未拖出默认位置，运行的是 World。若显示的是方框字符，请反馈现象，再处理字体配置。

文字和颜色都没有恢复

圆形碰撞半径约 87.3，图标中心退出不代表碰撞形状已经退出。先按 S 退回出生点，再检查第四课的 body_exited 连接与离开日志。不要改 Trigger 的 Layer 来处理文字问题。
