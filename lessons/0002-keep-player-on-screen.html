Lesson 0002 · Godot 4 · 2D

把角色留在屏幕内

今天只做一件事：限制角色的位置，让整个 Godot 图标始终留在窗口内。

预计 10–20 分钟成果：带屏幕边界的移动 Demo语言：GDScript
完成标准

角色仍能八方向移动；推向窗口任意边缘时会停住；图标不会有一部分跑到窗口外。

1. 从上一课的输入向量开始

同时按 W 和 D 时，Input.get_vector() 返回的方向大约是 (0.707, -0.707)。它的长度约为 1，所以斜向移动不会比横向移动更快。

这一课不改输入和速度。移动完成后，我们只修正最终的 position。

2. 建立屏幕坐标模型

Godot 2D 窗口的坐标原点位于左上角。X 向右增大，Y 向下增大：

(0, 0) ───────────────→ X │ ┌───────────────────┐ │ │ │ │ │ Player │ │ │ │ ↓ └───────────────────┘ Y viewport.size
position 是角色中心
→
边界必须预留半个图标

当前图标是 128 × 128 像素，所以中心至少要离左边和上边 64 像素。窗口右边和下边也要减去 64 像素。

最小位置 = (64, 64)
最大位置 = 窗口尺寸 - (64, 64)

3. 让节点自己提供尺寸

不要在脚本里重复写 64。直接从 Sprite2D 的纹理读取尺寸：

@onready var half_size: Vector2 = $Sprite2D.texture.get_size() / 2.0

$Sprite2D：取得当前节点下名为 Sprite2D 的子节点。

texture.get_size()：读取纹理的完整尺寸，当前结果为 (128, 128)。

@onready：等节点和子节点都准备好后，再计算这个值。

4. 移动后限制位置

把 player.gd 改为：

extends CharacterBody2D

@export var speed: float = 300.0
@onready var half_size: Vector2 = $Sprite2D.texture.get_size() / 2.0

func _physics_process(_delta: float) -> void:
    var direction := Input.get_vector(
        "move_left",
        "move_right",
        "move_up",
        "move_down"
    )
    velocity = direction * speed
    move_and_slide()

    position = position.clamp(
        half_size,
        get_viewport_rect().size - half_size
    )

Vector2.clamp(min, max) 分别限制 X 和 Y。小于最小值时取最小值，大于最大值时取最大值，中间的值保持不变。

注意执行顺序

先调用 move_and_slide()，再限制 position。这样每次物理更新都先计算移动结果，然后把越界的位置拉回合法范围。

5. 运行三个实验

  1. 运行场景，把角色分别推向窗口的四条边，确认整个图标始终可见。
  2. 把角色推向右下角，确认 X 和 Y 可以同时到达各自的最大值。
  3. 运行时调整窗口大小，再推向边缘，确认边界会跟随当前窗口尺寸。

如果图标仍有一半跑出窗口，通常是把角色中心限制在 0 到窗口尺寸之间，却没有预留 half_size。

6. 不看代码，先回答

判断：从纹理计算 half_size 比固定写成 Vector2(64, 64) 更可靠。
