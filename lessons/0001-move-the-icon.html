Lesson 0001 · Godot 4 · 2D

让 Godot 图标动起来

今天只做一件事：用方向键或 WASD 控制 Godot 图标八方向移动。完成后，你会拥有第一个可玩的场景。

预计 15–25 分钟成果：可运行移动 Demo语言：GDScript
完成标准

角色可向四个基本方向及四个对角方向移动；松开按键后立刻停止；对角移动不会更快。

1. 先建立正确模型

Godot 用“小节点组合”构成对象。角色不是一个包办所有职责的大类，而是一棵节点树。官方文档把节点称为游戏的基本构件，把保存后的节点树称为场景。参见 Nodes and Scenes。

Player (CharacterBody2D) ← 移动与碰撞 ├── Sprite2D ← 显示图像 └── CollisionShape2D ← 定义碰撞形状
Java：一个类通过依赖对象获得能力
→
Godot：一个场景通过子节点组合能力

2. 创建项目与角色场景

  1. 若尚未安装，从 Godot 官方下载页取得当前稳定版标准编辑器。
  2. 新建项目，建议目录为本工作区下的 demo/character-movement。渲染器保持默认即可。
  3. 点击 Other Node，创建根节点 CharacterBody2D，重命名为 Player。
  4. 给 Player 添加两个子节点：Sprite2D 与 CollisionShape2D。
  5. 把项目自带的 icon.svg 拖到 Sprite2D 的 Texture。
  6. 在 CollisionShape2D 的 Shape 新建 CircleShape2D，让圆大致包住图标。
  7. 保存场景为 player.tscn。
立即验证

场景树应与上图一致，而且 2D 视图中能看到图标。看不到时，先检查 Sprite2D.Texture，不要继续写代码。

3. 用“动作”描述输入

打开 Project → Project Settings → Input Map，添加四个动作，并分别绑定方向键与 WASD：

  • move_left：Left、A
  • move_right：Right、D
  • move_up：Up、W
  • move_down：Down、S

代码读取“向左移动”这个意图，而不是硬编码 A 键。日后换手柄时，移动代码不必改变。

4. 附着移动脚本

选中 Player，点击 Attach Script，保存为 player.gd，替换为：

extends CharacterBody2D

@export var speed: float = 300.0

func _physics_process(_delta: float) -> void:
    var direction := Input.get_vector(
        "move_left",
        "move_right",
        "move_up",
        "move_down"
    )
    velocity = direction * speed
    move_and_slide()

逐行理解，而不是背诵

extends CharacterBody2D：脚本继承角色身体，因此直接拥有 velocity 与 move_and_slide()。

@export：让速度出现在 Inspector 中。它类似可由工具配置的字段。

_physics_process：引擎按固定物理节奏调用的回调。不是你主动调用它。

Input.get_vector()：把四个输入动作合成为长度不超过 1 的方向向量，所以斜向移动不会额外加速。

move_and_slide()：使用当前 velocity 移动身体，并处理滑动碰撞。它已按物理步长处理移动。

这套写法来自 Godot 官方的 2D movement overview。

5. 运行并做一次有意的实验

  1. 运行当前场景。若 Godot 要求主场景，选择当前的 player.tscn。
  2. 同时按 W 与 D，确认能斜向移动。
  3. 运行中停止，选中 Player，把 Inspector 中的 Speed 改成 100，再次运行。

这个实验验证了：脚本声明行为，场景保存配置，两者共同构成可复用角色。
