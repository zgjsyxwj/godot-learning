进入变色，离开恢复

把第三课的日志变成可见反馈：角色进入 Trigger 后变色，停留时保持，完全离开后恢复，再次进入仍能变色。

第四课 · 约 15 分钟Godot 4.7.2 · GDScript状态：2026-09-14 已确认完成
本课只做这一项成果

复用现有区域，用进入与离开信号控制角色颜色。你在编辑器中修改 world.gd；课程准备没有替你修改游戏文件。

1. 打开已有 World，核对起点

第三课你已确认能穿过区域、停留只输出一次，并知道 Player 是 body。重新进入与 Mask 实验尚未单独反馈，本课不把它们当作已验证结果。

以下面板名称已对照本机 Godot 4.7.2 英文界面。先完成这一小步，不急着粘贴代码。

  1. 在编辑器左下 FileSystem（文件系统） 面板展开 res://，双击 world.tscn。顶部场景标签应是 world。
  2. 在左上 Scene（场景） 面板单击根节点 World。核对其下有同级的 Player、Wall、Trigger；Trigger 下有 CollisionShape2D。
  3. 在左下 FileSystem 双击 world.gd。中央切到 Script（脚本） 工作区；确认代码编辑区顶部文件名是 world.gd，首行是 extends Node2D。
  4. 找到 _ready() 中已有的 trigger.body_entered.connect(...)，以及下方输出“角色进入触发区域”的方法。稍后在这些位置扩展。
World (Node2D) ← world.gd 在这里 ├── Player (CharacterBody2D) ← 修改 modulate │ └── Sprite2D ← 图标继承颜色调制 ├── Wall (StaticBody2D) └── Trigger (Area2D) └── CollisionShape2D

图中省略 Player 和 Wall 的碰撞子节点；保留它们。当前 Player 在 (163, 283)，Trigger 在 (180, 100)，出生时不重叠。本课沿用这些位置。

项目中的 Trigger 没有显式取消默认 Layer，第 1 层仍启用；其 Mask 第 1 层可检测 Player。这不妨碍本课。沿用当前有效配置，不把“清空 Trigger Layer”作为前置操作。

2. 事件改变状态，状态留在画面上

原色 ── body_entered(Player) ──→ 变色 变色 ── body_exited(Player) ──→ 原色 停留：没有新的进入事件，颜色保持

body_exited 是角色离开区域时的信号，与已学过的 body_entered 配对。这里“离开”指碰撞形状不再重叠，不是图标中心刚越过边缘。参见 官方 body_exited 说明。

Java：事件监听器修改对象属性
方法返回后，属性仍保留新值
→
Godot：信号接收方法修改颜色
每次绘制使用当前属性值

所以不需要每帧重复赋值。World 继续负责响应区域事件；Player 原有的移动逻辑不需要知道 Trigger。

3. 在 world.gd 中补齐两个方向

3.1 先保存原色

保持中央 Script 编辑区打开 world.gd。在两行已有的 @onready 声明下面、func _ready() 上面，新增这一行，顶格写：

@onready var original_modulate: Color = player.modulate

让这一行排在 player 的声明之后。这样在准备阶段取得 Player 后，再保存它的初始颜色调制值。我们要恢复原值，而不是猜原值是什么。

3.2 进入时变色，离开时恢复

  1. 在 _ready() 的已有连接下面新增 trigger.body_exited.connect(_on_trigger_body_exited)，缩进与已有连接相同，为一个 Tab。不要重复连接 body_entered。
  2. 找到 _on_trigger_body_entered 中的 if body == player:。在已有 print 下一行添加 player.modulate = Color(1.0, 0.45, 0.45, 1.0)，与 print 对齐，为两个 Tab。
  3. 在文件末尾新增下面的离开方法。func 顶格，if 缩进一个 Tab，赋值和 print 缩进两个 Tab。
func _on_trigger_body_exited(body: Node2D) -> void:
	if body == player:
		player.modulate = original_modulate
		print("角色离开触发区域")

Color 的四个数依次为红、绿、蓝、透明度。这里降低绿、蓝分量，保持透明度为 1，让图标带红色调。图标本身有颜色，因此不一定呈现纯红色。

modulate 来自 CanvasItem，Node2D 及 CharacterBody2D 都继承它。它会与图像颜色相乘，并影响子 CanvasItem，所以修改 Player 能影响其 Sprite2D。self_modulate 只影响节点自身，不会这样传给 Sprite2D；本课使用 modulate。它不改变碰撞形状或速度。参见 官方 modulate 属性。

本课只在脚本里设置颜色，不需要打开 Inspector 的颜色选择器。两个接收方法都检查 body == player，只响应这个角色实例。

动手后展开：完整 world.gd 核对版 
extends Node2D

@onready var player: CharacterBody2D = $Player
@onready var trigger: Area2D = $Trigger
@onready var original_modulate: Color = player.modulate

func _ready() -> void:
	trigger.body_entered.connect(_on_trigger_body_entered)
	trigger.body_exited.connect(_on_trigger_body_exited)

func _on_trigger_body_entered(body: Node2D) -> void:
	if body == player:
		print("角色进入触发区域")
		player.modulate = Color(1.0, 0.45, 0.45, 1.0)

func _on_trigger_body_exited(body: Node2D) -> void:
	if body == player:
		player.modulate = original_modulate
		print("角色离开触发区域")

4. 保存，运行一个完整往返

  1. 点击中央 world.gd 代码区，macOS 按 ⌘S 保存脚本；Windows/Linux 按 Ctrl+S。确认没有红色语法错误。
  2. 单击顶部 world 场景标签，按 F6（Run Current Scene，运行当前场景）；Mac 功能键被系统占用时按 Fn+F6。必须运行 World，单独运行 Player 没有区域。
  3. 点击游戏画面获得键盘焦点。出生时应保持原色。短按 W 靠近上方 Trigger，每次约 0.1 秒，直到图标变色后立刻松开。不要一直按到屏幕外。
  4. 停留两秒：颜色保持，进入日志不持续增加。无需再次触发事件来维持颜色。
  5. 按 S 退回出生点附近：碰撞形状完全离开后恢复原色，出现一次离开日志。再按 W 接近，应再次变色并新增一次进入日志。
  6. 日志位置：返回编辑器后点击底部 Output（输出） 标签。应按顺序看到“进入 → 离开 → 进入”。回到游戏前再次点击游戏画面。
  7. 再退回出生点，按 D 撞墙：应仍会停住。保持 D 短按 W，应仍沿墙向上移动；松开后停止。这里是速度沿墙的分量得以保留。
  8. 点击编辑器右上角方形 Stop（停止） 按钮，或按 F8（必要时 Fn+F8）。点击底部 Debugger（调试器），查看 Errors（错误），本次运行应没有新增错误。

无需开启碰撞可视化才能看到变色。若上一课已开启，可以保留；圆形碰撞半径约 87.3，图标中心在区域外时仍可能重叠。不要用图标边缘代替碰撞边缘判断退出。

验收结果

出生原色 → 进入变色 → 停留保持 → 完全离开恢复 → 再次进入变色。墙仍阻挡，调试器无新增错误。请用你的实际运行结果确认这条链。

5. 按现象定位问题

有进入日志，但图标不变色

检查赋值是否位于 if body == player: 内，是否写成了 player.modulate，是否保存了 world.gd。不要误写成 World 自己的 modulate 或 Player 的 self_modulate。

变色后不恢复

先按 S 回到出生点附近，确保整个碰撞圆已离开。如果没有离开日志，检查 _ready() 中是否连接 body_exited，方法名是否一致；如果有离开日志，检查恢复赋值是否存在，以及保存原色是否在首次变色之前执行。

没有进入日志，也没有变色

先确认运行 World、脚本挂在 World、游戏窗口有键盘焦点。只有检测失效时再核对配置：

  1. 停止运行，打开 world.tscn，在左上 Scene 选中 Trigger。
  2. 右侧 Inspector（检查器） 清空 Filter Properties（筛选属性）。在 Area2D → Monitoring（监测） 确认勾选。
  3. 向下展开 CollisionObject2D → Collision（碰撞）→ Mask（掩码），确认数字 1 已选中；已选中就不要再点击。保留 Layer。
  4. 在 Scene 选中 Player，到 Inspector → CollisionObject2D → Collision → Layer（层），确认第 1 层选中。
  5. 若有修改，点击顶部 world 标签，通过 Scene（场景）→ Save Scene（保存场景） 保存，再按 F6。macOS 的 Scene 菜单位于屏幕顶部菜单栏。
