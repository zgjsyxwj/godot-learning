Godot 基础速查

从 Java 开发者的视角，压缩 Godot 最重要的几个概念。

核心词汇

节点 Node：只负责一种能力的运行时对象。显示、碰撞、摄像机、音频通常由不同节点承担。

场景 Scene：一棵保存到磁盘的节点树。场景可被实例化和组合，像项目自定义的新节点类型。

场景树 SceneTree：当前正在运行的全部节点形成的树。节点进入树后才参与生命周期。

脚本 Script：附着到节点，为该节点增加状态与行为。首行 extends 决定脚本继承的节点类型。

输入动作 Input Action：业务含义明确的输入名称，例如 move_left。键盘键只是它的绑定。

Java 类比：只作桥梁

extends CharacterBody2D
→
类似继承引擎基类
func _physics_process(delta)
→
类似框架定期调用的回调
@export var speed
→
类似可由编辑器配置的字段

重要区别：场景不是 Java 类文件，节点树也不是普通对象图。它们由引擎加载、挂接并调度。

本课程的移动流水线

输入动作 → 方向向量 → velocity → move_and_slide()

碰撞：第二课速查

CharacterBody2D
由脚本控制的角色身体。用 velocity 表达速度，用 move_and_slide() 执行移动。
StaticBody2D
本课的不动墙壁。作为障碍物参与碰撞。
CollisionShape2D
直接挂在碰撞对象下。Shape 资源定义轮廓；图片不决定碰撞边界。
Floating
俯视移动模式。所有碰撞按墙处理，适合本课八方向移动。

最小组合：角色身体 + 角色形状；静态身体 + 墙形状；匹配的碰撞层与掩码；在物理回调中调用移动方法。

先输入，再设置 velocity，最后 move_and_slide()。速度单位是像素/秒，不乘 delta。
